# auditoria-seguranca-windows
Projeto prático de auditoria de segurança em ambiente Windows, com análise de antivírus, firewall e atualizações.
Auditoria de Segurança do Windows

Sobre o projeto

Este projeto tem como objetivo realizar uma auditoria básica de segurança em um ambiente Windows, verificando os principais mecanismos de proteção do sistema operacional.

Objetivos

Verificar a proteção antivírus.

Analisar o status do firewall.

Conferir atualizações de segurança.

Verificar recursos de segurança do dispositivo.

Documentar resultados e possíveis melhorias.
